Practica 4

Funcionalidades
- Formulario para ingresar: Nombre, Edad, Ciudad y Correo electrónico.
- Validación de campos.
- Pantalla de resumen de datos.
- Confirmación del perfil con mensaje Toast.
- Soporte para rotación de pantalla 
- Uso de `registerForActivityResult`.

Tecnologías utilizadas
- **Lenguaje:** Kotlin
- **Arquitectura:** Activities + Intents
- **Componentes:**
    - `AppCompatActivity`
    - `Serializable` (data class `Usuario`)
    - `registerForActivityResult`
    - `onSaveInstanceState`
